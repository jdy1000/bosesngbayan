Failures, root causes and fixes
1. npm install hung for >20 min (network fine at 6 MB/s). Cause: npm resolver stall on Windows with the
   scaffold lock. Fix: killed processes, switched to pnpm (packageManager pnpm@11.13.1). Verified install.
2. SECURITY: is_service_context() originally trusted current_user, which is the function OWNER inside
   SECURITY DEFINER functions, so every definer RPC looked like service context. Fix: use JWT role claim
   plus session_user. Covered by tests "cast_vote denied for anon/staff" and scheduler denial tests.
3. profiles_guard used a session flag that definer functions could not set reliably. Fix: guard on
   current_user in ('authenticated','anon') (direct API) vs definer RPC owner. Test: is_active direct update blocked.
4. can_view_article referenced article_contributors before creation -> migration failed. Fix: reorder.
5. Route module exported REPORT_REASONS (Next route files may only export handlers) -> moved to src/lib/report-reasons.ts.
6. pnpm 11 refused to run scripts: "ERR_PNPM_IGNORED_BUILDS esbuild". Fix: allowBuilds.esbuild=true in
   pnpm-workspace.yaml. Verified `pnpm db:types` runs.
7. typecheck: RPC args passed as `?? undefined` for parameters WITHOUT SQL defaults. Root cause: omitted
   keys make PostgREST look up a different function signature (404 at runtime). Fix: pass `null`
   explicitly; type generator now emits `T | null` for RPC args. Verified typecheck + tests.
